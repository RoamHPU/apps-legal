# Roam HPU Apps — Legal & Support

Privacy policies, terms of use, and support pages for our published iPhone apps.

Hosted at https://roamhpu.github.io/apps-legal/

## Apps covered
- ReceiptSnap by Roam (`com.roamhpu.ReceiptSnap`)
- FileSnap Docs by Roam (`com.roamhpu.FileSnapDocs`)

## Source
The HTML is generated from markdown source that lives alongside each app:
- `iOS_Apps/receipt-snap/store/{privacy-policy,support,terms}.md`
- `iOS_Apps/file-snap-docs/store/{privacy-policy,support,terms}.md`

Run `python3 build.py` after editing source markdown to regenerate the HTML.
